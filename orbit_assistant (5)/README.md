# ORBIT · два приложения для Windows

**Orbit Settings** — окно настроек. Здесь можно выбрать микрофон, положение островка, модель ИИ, озвучку, игровой режим и макросы MSI, посмотреть демо, запустить или остановить помощника. **Orbit Assistant** — фоновый голосовой помощник с компактным островком, Vosk, Gemini/OpenAI и Fish Audio/Edge TTS.

## Как получить два EXE

Сборка выполняется на **Windows 10/11 x64** с Python **3.11 или 3.12**. PyInstaller собирает исполняемые файлы для той системы, на которой запущен. Команды выполняются в папке с `settings_app.py`, `assistant_app.py` и `requirements.txt`:

```powershell
python -m pip --version
python -m pip install --user -r .\requirements.txt pyinstaller
python .\build_windows.py
```

Можно вместо двух последних команд открыть `build-exe.bat`. Если в системном Python отсутствует `pip`, сначала восстанови его установщиком Python (Modify/Repair); незавершённое `.venv` с `No module named pip` сборку не выполнит. Сборщик при необходимости скачает официальную русскую модель Vosk и **включит её внутрь `Orbit Assistant.exe`**. Для запуска готовых программ Python и отдельная модель не нужны. Созданные файлы:

Если сборка остановилась с `PermissionError: [WinError 5]` именно внутри `subprocess.Popen` / `_winapi.CreateProcess`, Windows отказала в запуске дочернего `python.exe`. Это отдельная проблема от установки пакетов; проверь «Безопасность Windows → Журнал защиты». Для точной проверки в PowerShell: `python -c "import subprocess,sys; subprocess.run([sys.executable,'-I','-c','print(123)'],check=True)"`. Если и эта команда выдаёт WinError 5, локальная сборка не начнётся до устранения запрета. Отключать защиту целиком не требуется: ниже есть вариант с GitHub Actions.

Если сборка на твоём ПК пока не получается из-за сломанного `pip`, в проекте также лежит `.github/workflows/build-windows.yml`: при загрузке **исходников без `.env` и ключей** в свой репозиторий GitHub запусти Actions → Build Orbit Windows EXE → Run workflow, затем скачай артефакт `ORBIT-Windows`. Это запасной способ получить те же два файла на Windows-сервере сборки.

- `dist\Orbit Settings.exe` — настройка и кнопки управления.
- `dist\Orbit Assistant.exe` — сам помощник. Оба файла держи рядом: кнопка запуска в настройках ищет второй EXE в той же папке.

Сборка с моделью занимает время и дисковое пространство. Режим одного файла PyInstaller распаковывает компоненты во временную папку при запуске; это может замедлять первый старт. В процессе игры помощник завершает рабочий процесс с моделью и оставляет наблюдатель за играми.

## Первое включение

1. Открой `Orbit Settings.exe`. Выбери микрофон и место появления островка; проверь анимацию кнопкой «Посмотреть анимацию».
2. В разделе «ИИ и голос» выбери Gemini либо OpenAI и вставь соответствующий ключ. Рыбий голос необязателен: для Fish Audio укажи `FISH_API_KEY` и `reference_id` выбранного голоса. Без Fish помощник использует Edge TTS; при проблемах с сетью попробует голос Windows.
3. Нажми «Сохранить изменения» и «Запустить помощника». Окно помощника скрыто, пока не произнесёшь «Джарвис» или «Компьютер». Произнеси команду после появления островка.
4. Для остановки открой настройки и нажми «Остановить помощника». После изменения настроек перезапусти помощника этими кнопками.

Настройки (`config.toml`), ключи (`.env`) и голосовой образец хранятся в `%LOCALAPPDATA%\OrbitAssistant`. **API-ключи в `.env` не шифруются**: они не помещаются внутрь EXE, но доступны людям и программам с доступом к твоему профилю Windows. Не публикуй эти файлы. Сведения об ошибках фонового помощника — `%LOCALAPPDATA%\OrbitAssistant\orbit.log`. Для сборки из исходников данные остаются в папке проекта.

## Шумоподавление и свой голос

Фильтр микрофона включён по умолчанию: он подавляет тихий фон и ослабляет звуки вне речевой полосы. При одновременном разговоре телевизор и твой голос одним микрофоном надёжно разделить нельзя. Дополнительно можно включить проверку говорящего: в настройках микрофона нажми «Скачать модели и записать мой голос». Выключи телевизор и произнеси несколько фраз **непрерывно 10 секунд**, затем поставь галочку проверки голоса и сохрани. Модели для записи (основная и дополнительная 13 МБ) сохраняются рядом с настройками, а сам образец остаётся локальным. Короткие команды иногда отвергаются: сравнение по длинным репликам устойчивее. При включённой проверке чужой или неопределённый голос не выполняет команды. Запись твоего голоса на телевизоре тоже может пройти проверку.

## Макросы и игровой режим

Координаты профилей MSI Center зависят от размера экрана и версии приложения. Укажи расположение **обеих** кнопок, проверь заголовок окна и только потом разреши управление в настройках. Программа проверяет активное окно перед кликом; голосовой ответ сам по себе не подтверждает фактическую смену режима MSI.

Укажи названия процессов игр (например, `cs2.exe`). Каждые пять секунд наблюдатель проверяет список процессов, выгружает модель/виджет при появлении игры и запускает их снова после закрытия игры. Точное потребление RAM зависит от Windows и установленных компонентов.

## Запуск из исходников

```powershell
python -m pip install --user -r .\requirements.txt
python .\settings_app.py
python .\assistant_app.py --demo
```

`settings.bat` открывает настройки, `demo.bat` показывает островок, `run.bat` запускает обычный процесс. Для живого помощника нужна модель в `models\vosk-model-small-ru-0.22`; `python build_windows.py` скачивает её перед сборкой. После сборки модель уже внутри EXE. Путь `orbit\worker.py` должен находиться рядом с `requirements.txt`, а не уровнем глубже.

Сборка не была проверена на твоём Windows из этой среды. Если запуск EXE даст ошибку, загляни в `orbit.log` и пришли текст ошибки. Если `.exe` пока не собирается из-за отсутствующего `pip`, само приложение настроек можно проверить после установки зависимостей командой `python settings_app.py`.
